# nowplaying

A terminal dashboard that shows what's currently playing on Spotify, styled
like `btop` — album art rendered as colored terminal blocks, an animated
equalizer, a vertical volume meter, up next / recently played, and live
CPU / memory / disk meters. Designed to look good full-screen on small
displays (tested on a 1024x600 touchscreen) but works in any terminal.

Pure Python standard library plus one small external tool (`chafa`) for
rendering album art. No pip packages, no accounts beyond your own Spotify
developer app, no server to run.

## Install

```bash
git clone https://github.com/<your-username>/nowplaying.git
cd nowplaying
./install.sh
```

That installs `chafa` (if missing), copies the app to `/opt/nowplaying`, and
adds a `nowplaying` command to your PATH.

Then authorize with your Spotify account (one-time, ~2 minutes):

```bash
cd /opt/nowplaying
python3 authorize.py
```

It walks you through creating a free Spotify developer app, then a single
copy-paste of one URL — no domain, no web server, no Docker required. It
saves everything into a local `.env` file for you.

Once that's done:

```bash
nowplaying
```

Ctrl+C to quit.

## Requirements

- Linux or macOS with Python 3.8+
- A Spotify account (free or Premium both work for reading playback state)
- `chafa` for album art (the installer handles this; the app still runs
  without it, just without art)

## Manual install

If you'd rather not run `install.sh`:

1. Install `chafa` via your package manager (`apt install chafa`, `brew
   install chafa`, etc.)
2. Run `python3 authorize.py` from wherever you keep the files
3. Run `python3 nowplaying.py`

## Configuration

Everything is read from a `.env` file next to `nowplaying.py` (created
automatically by `authorize.py`), or from real environment variables if you
prefer:

| Variable | Required | Description |
|---|---|---|
| `SPOTIFY_CLIENT_ID` | yes | From your Spotify developer app |
| `SPOTIFY_CLIENT_SECRET` | yes | From your Spotify developer app |
| `SPOTIFY_REFRESH_TOKEN` | yes | Generated by `authorize.py` |
| `NOWPLAYING_EXTRA_DISKS` | no | Extra disk usage bars, e.g. `/mnt/data:DATA` |

See `.env.example` for the full template.

## Notes

- Polls Spotify every 3 seconds (well under rate limits); the on-screen
  progress bar advances locally between polls so it stays smooth.
- CPU/memory/disk stats are read directly from `/proc` and `statvfs` - no
  extra dependencies.
- Designed for terminals that support 24-bit color. Most modern terminal
  emulators do; the bare Linux console (no X/Wayland) does too via the
  framebuffer console, which is what this was originally built for.
- The `authorize.py` flow uses a loopback redirect URI
  (`http://127.0.0.1:8888/callback`) that never actually needs to be
  reachable - Spotify just needs it registered, and the code appears in
  your browser's address bar after you approve, which you paste back in.
